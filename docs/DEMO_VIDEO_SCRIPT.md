# Demo Video Script

Target duration: 6–8 minutes. Use synthetic data only.

1. **Architecture and safety** — tenant boundaries, PostgreSQL queue, controlled tools,
   mock EHR and the non-clinical notice.
2. **Isolation** — switch hospitals and show tenant-scoped patients, campaigns and queue.
3. **Ingestion and campaign** — import a discharge, explain eligibility and workload.
4. **Queue correctness** — show capacity, priority, retries, callback, deadline and recovery.
5. **Conversation** — run routine and urgent synthetic conversations; inspect structured
   assessments, protocol references, consensus and documentation.
6. **Human review** — assign and resolve an escalation; inspect EHR, notification and audit.
7. **Evaluation** — show false-negative metrics, health, AI traces and tests.
8. **Tradeoffs** — disclose simulated telephony/EHR and no compliance certification.

Finish with the public deployment, source repository and requirements traceability table.
