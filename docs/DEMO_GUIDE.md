# Evaluator Demo Guide

1. Open the operations overview and switch between the two hospitals to demonstrate
   tenant-scoped data.
2. Open **Outreach Queue** and advance the deterministic simulation.
3. Show active calls never exceed configured capacity.
4. Observe priority changes, no-answer/busy/voicemail outcomes, retries, callbacks,
   escalation, and manual follow-up.
5. Open **Campaigns**, **Patients**, and **Escalations** to show the connected workflow.
6. Open **Safety Evaluation** and explain the false-negative metric.
7. Use the API documentation to import a validated synthetic discharge batch.
8. Run structured triage on an urgent synthetic transcript and inspect the controlled mock
   EHR record.
9. Update an escalation as a clinical reviewer and inspect the resulting audit record.
10. Show health, queue metrics, design documents, automated tests, and known limitations.

Never enter real patient information into the prototype.
